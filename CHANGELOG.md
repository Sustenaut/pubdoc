Generated by `pubrel changelog` from the package publet `pkg.pubdoc` [PKG-PUBDOC-11-2026] in `corpus/`. Do not edit: each release is a published version of that publet, and this file is a view of it.

## 0.2.0 - 2026-11-19

Commit `e72cca453bea`; release record `pub:sha2-256:rpind6yr25di2sznrdd5yol4rcj775llvb4jlho3qxq4pilxr2hq`.

### Changed
- pubdoc builds document projects: a project.yml (parts, variants, layouts, review steps, publications; schema shipped in the package) and one directory of MyST parts per doc, with shared parts docs start from, <part>.<variant>.md overrides and an optional doc.yml that only narrows; build, preview and approve take <project>/<doc> and write <doc>/build/<variant>/<layout>.<ext> (build/ ignores itself) and <doc>/versions/; the old layout, a myst.yml and per-variant review-builder.yaml in each document, is gone, and init no longer touches .gitignore

### Added
- pubdoc check validates every project.yml and doc.yml git knows of, in any repository: the schema, every name they refer to, each doc's required parts and that doc.yml only narrows; pubdoc list shows projects and their docs; pubdoc new-project starts one; checkers and places are named now and noted as not implemented yet

### Internal
- pubkit is now pubrules: the repository runs on pubrules 0.43.0 (pubrules.json, ./pubrules, the managed workflows and test pins)

## 0.1.2 - 2026-11-13

### Added
